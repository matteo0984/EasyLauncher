Guía paso a paso: obtener las claves API de IGDB

EasyLauncher — Frontend Retro 100% Portable & Open Source

¿Qué es IGDB y por qué necesitas una cuenta de Twitch?

IGDB (Internet Game Database) es una de las bases de datos de videojuegos más completas del mundo, gestionada por Twitch / Amazon.

EasyLauncher funciona 100% en local en tu PC sin servidores intermedios. Para consultar IGDB necesitas un Client ID y un Client Secret gratuitos de Twitch Developer.

Duración de las claves: El Client ID y el Client Secret no caducan. EasyLauncher renueva el token temporal automáticamente.
PASO 1

Inicia sesión en Twitch y activa la verificación en dos pasos (2FA)

Twitch exige 2FA para registrar una aplicación de desarrollador. Sin 2FA verás el error: "user must have two factor auth enabled to perform this action".

  • Si no tienes cuenta de Twitch, crea una gratis en https://www.twitch.tv/.
  • Abre la configuración de seguridad y activa la 2FA:
Abrir Seguridad de Twitch (Activar 2FA)
PASO 2

Abre la Consola de Desarrolladores de Twitch

Con la 2FA activa, abre la consola de Twitch y haz clic en Registrar aplicación:

Consola de Desarrolladores Twitch Registrar nueva aplicación
PASO 3

Rellena el formulario «Registrar aplicación»

  • Nombre: elige un nombre único (3–100 caracteres, ej. EasyLauncher).
  • URL de redirección OAuth: escribe exactamente https://localhost.
  • Categoría: selecciona Application Integration.
  • Tipo de cliente: selecciona Confidencial (necesario para el Client Secret).
  • Haz clic en Crear abajo.
Cuidado con los errores comunes:
1) Usa https://localhost (con HTTPS).
2) No dejes un segundo campo de URL vacío.
PASO 4

Copia «ID de cliente» y genera el «Secreto de cliente»

  • Vuelve a Tus Aplicaciones y pulsa Administrar.
  • Copia el ID de cliente.
  • Pulsa Nuevo secreto y copia de inmediato el Secreto de cliente.
PASO 5

Introduce las claves en EasyLauncher

  • Abre EasyLauncher → Herramientas → Descargar Metadatos → Ajustes de Metadatos.
  • En IGDB (Twitch Developer) pega Client ID y Client Secret.
  • Pulsa Guardar Ajustes (se guarda localmente en data/config.json).

Documentación oficial de IGDB: https://api-docs.igdb.com/#account-creation

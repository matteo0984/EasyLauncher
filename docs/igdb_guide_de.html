Schritt-für-Schritt-Anleitung: IGDB-API-Schlüssel erhalten

EasyLauncher — 100% Portables & Open-Source Retro-Frontend

Was ist IGDB und warum wird ein Twitch-Konto benötigt?

IGDB (Internet Game Database) ist eine der umfangreichsten Spieledatenbanken der Welt und wird von Twitch / Amazon betrieben.

EasyLauncher läuft zu 100 % lokal auf Ihrem PC ohne Zwischenserver. Für direkte IGDB-Abfragen benötigen Sie eine kostenlose Client ID und ein Client Secret über Twitch Developer.

Gültigkeit: Client ID und Client Secret laufen nie ab. EasyLauncher erneuert das temporäre Zugriffstoken automatisch.
SCHRITT 1

Bei Twitch anmelden und 2FA aktivieren

Twitch verlangt zwingend die Zwei-Faktor-Authentifizierung (2FA). Ohne 2FA erscheint der Fehler: "user must have two factor auth enabled to perform this action".

  • Falls Sie noch kein Twitch-Konto haben, erstellen Sie kostenlos eines unter https://www.twitch.tv/.
  • Öffnen Sie die Sicherheitseinstellungen und aktivieren Sie 2FA:
Twitch-Sicherheit öffnen (2FA aktivieren)
SCHRITT 2

Twitch Developer Console öffnen

Öffnen Sie nach Aktivierung der 2FA die Twitch Developer Console und klicken Sie auf Anwendung registrieren:

Twitch Developer Console Neue Anwendung registrieren
SCHRITT 3

Formular «Anwendung registrieren» ausfüllen

  • Name: eindeutigen Namen wählen (3–100 Zeichen, z. B. EasyLauncher).
  • OAuth-Weiterleitungs-URLs: exakt https://localhost eingeben.
  • Kategorie: Application Integration wählen.
  • Client-Typ: Vertraulich (Confidential) wählen (für das Client Secret).
  • Unten auf Erstellen klicken.
Häufige Fehler vermeiden:
1) Unbedingt https://localhost (mit HTTPS) verwenden.
2) Kein zweites leeres URL-Feld offen lassen.
SCHRITT 4

«Client-ID» kopieren und «Client-Geheimnis» erzeugen

  • Zurück zu Ihre Anwendungen und auf Verwalten klicken.
  • Client-ID kopieren.
  • Auf Neues Geheimnis klicken und das Client-Geheimnis sofort kopieren.
SCHRITT 5

Schlüssel in EasyLauncher eintragen

  • Öffnen Sie EasyLauncher → Werkzeuge → Metadaten herunterladen → Metadaten-Einstellungen.
  • Fügen Sie unter IGDB (Twitch Developer) Client ID und Client Secret ein.
  • Klicken Sie auf Einstellungen speichern (lokal in data/config.json gespeichert).

Offizielle IGDB-Dokumentation: https://api-docs.igdb.com/#account-creation

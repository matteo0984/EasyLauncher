Guide étape par étape : obtenir les clés API IGDB

EasyLauncher — Frontend Rétro 100% Portable & Open Source

Qu'est-ce qu'IGDB et pourquoi faut-il un compte Twitch ?

IGDB (Internet Game Database) est l'une des bases de données de jeux vidéo les plus complètes au monde. Elle est gérée par Twitch / Amazon.

EasyLauncher fonctionne à 100% en local sur votre PC sans serveur intermédiaire. Pour interroger IGDB, vous avez besoin d'un Client ID et d'un Client Secret gratuits via votre compte Twitch Developer.

Durée des clés : Le Client ID et le Client Secret n'expirent jamais. EasyLauncher renouvelle automatiquement le jeton d'accès temporaire.
ÉTAPE 1

Connectez-vous à Twitch et activez l'A2F (2FA)

Twitch exige l'authentification à deux facteurs (2FA) pour enregistrer une application. Sans 2FA, l'erreur suivante apparaît : "user must have two factor auth enabled to perform this action".

  • Si vous n'avez pas de compte Twitch, créez-en un gratuitement sur https://www.twitch.tv/.
  • Ouvrez les paramètres de sécurité et activez la 2FA :
Ouvrir Sécurité Twitch (Activer 2FA)
ÉTAPE 2

Ouvrir la Console Développeur Twitch

Une fois la 2FA activée, ouvrez la console Twitch et cliquez sur Enregistrer votre application :

Console Développeur Twitch Enregistrer une application
ÉTAPE 3

Remplir le formulaire « Enregistrer votre application »

  • Nom : choisissez un nom unique (3–100 caractères, ex. EasyLauncher).
  • URL de redirection OAuth : saisissez exactement https://localhost.
  • Catégorie : sélectionnez Application Integration.
  • Type de client : sélectionnez Confidentiel (pour obtenir le Client Secret).
  • Cliquez sur Créer en bas.
Attention aux erreurs courantes :
1) Utilisez bien https://localhost (avec HTTPS).
2) Ne laissez pas un deuxième champ d'URL vide.
ÉTAPE 4

Copier « ID client » et générer le « Secret client »

  • Retournez sur Vos Applications et cliquez sur Gérer.
  • Copiez l'ID client.
  • Cliquez sur Nouveau secret et copiez immédiatement le Secret client.
ÉTAPE 5

Saisir les clés dans EasyLauncher

  • Ouvrez EasyLauncher → Outils → Télécharger les Métadonnées → Paramètres Métadonnées.
  • Dans la section IGDB (Twitch Developer), collez Client ID et Client Secret.
  • Cliquez sur Enregistrer les Paramètres (sauvegardé localement dans data/config.json).

Documentation officielle IGDB : https://api-docs.igdb.com/#account-creation

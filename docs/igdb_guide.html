Guida passo-passo: ottenere le chiavi API di IGDB

EasyLauncher — Frontend Retro 100% Portable & Open Source

Cos'è IGDB e perché serve un account Twitch?

IGDB (Internet Game Database) è uno dei database di videogiochi più completi al mondo (copertine, descrizioni, generi, anni di uscita, sviluppatori, valutazioni). È gestito da Twitch / Amazon.

A differenza di altri programmi che usano un server centrale privato per smistare le richieste, EasyLauncher funziona al 100% in locale sul tuo PC senza server intermedi. Per questo motivo, per interrogare direttamente le API ufficiali di IGDB servono un Client ID e un Client Secret gratuiti generati dal tuo account Twitch Developer.

Durata delle chiavi: Client ID e Client Secret valgono per sempre (non scadono, a meno che tu non li elimini o rigeneri). EasyLauncher richiede e rinnova in automatico il token temporaneo di accesso.
PASSO 1

Accedi a Twitch e attiva l'autenticazione a due fattori (2FA)

Twitch richiede obbligatoriamente che l'account abbia la verifica a due fattori (2FA) attiva prima di poter registrare un'applicazione sviluppatore. Senza 2FA compare l'errore rosso: "user must have two factor auth enabled to perform this action".

  • Se non hai un account Twitch, creane uno gratuito su https://www.twitch.tv/.
  • Apri le impostazioni di sicurezza del tuo account e attiva la 2FA (con app Authenticator o SMS):
Apri Sicurezza Twitch (Attiva 2FA)
PASSO 2

Apri la Console Sviluppatori Twitch

Una volta attivata la 2FA, entra nella Twitch Developer Console e clicca sul pulsante viola Registra l'applicazione (oppure apri direttamente il modulo di creazione):

Console Sviluppatori Twitch Registra nuova applicazione
PASSO 3

Compila il modulo «Registra l'applicazione»

  • Nome: scegli un nome univoco tra 3 e 100 caratteri (es. EasyLauncher o EasyLauncher123).
  • Reindirizzamento URL OAuth: scrivi esattamente https://localhost.
  • Categoria: seleziona Application Integration.
  • Tipo di client: seleziona Informazioni riservate (necessario per ottenere il Client Secret).
  • Clicca sul pulsante viola Crea in basso.
Attenzione ai due errori più comuni:
1) Devi usare https://localhost (con la S di HTTPS), altrimenti Twitch mostra l'errore rosso.
2) Non cliccare Aggiungi se non ti serve un secondo URL: se si apre un secondo campo vuoto, clicca Rimuovi su quello vuoto.
PASSO 4

Copia «ID client» e genera il «Segreto client»

  • Torna su Le tue Applicazioni e clicca Gestisci accanto alla tua app.
  • In basso trovi il campo ID client: copialo.
  • Subito sotto clicca sul pulsante viola Nuovo segreto: apparirà il Segreto client (copialo subito, perché se ricarichi la pagina non sarà più visibile).
PASSO 5

Inserisci i codici in EasyLauncher

  • Apri EasyLauncher → Strumenti → Scarica Metadati → Impostazioni Metadati.
  • Nella sezione IGDB (Twitch Developer) incolla Client ID e Client Secret.
  • Clicca Salva Impostazioni in basso a destra: i dati vengono salvati in locale in data/config.json.

Documentazione ufficiale IGDB: https://api-docs.igdb.com/#account-creation
